A NOTE FROM WAEL

Security starts where assumptions end.

I'm a Software Engineering graduate working at the intersection of offensive security, software assurance and applied security research. My approach is simple: go beyond a scanner result, understand the system, and explain the risk in a way people can act on.

From supervised penetration testing and secure code review to building EyeGuard, a network detection research platform, I care about both sides of the problem: how systems fail and how they recover.

EYEGUARD.

Network threats don't announce themselves.

EyeGuard is a passive, AI-driven Network Detection & Response research project that explores real-time network traffic processing, threat classification, anomaly detection, threat-intelligence enrichment and a roadmap toward richer response workflows.
