# WAEL / OBSIDIAN

An original, responsive, cybersecurity-focused personal portfolio for Wael El-Dabah. Live: https://wael-eldabah.github.io/

## Design and technical direction
- Editorial luxury × security engineering, graphite/obsidian with ultraviolet, mint and ice accents.
- Original code-drawn, physically projected 3D stone shards and 4D hypercube geometry: **Canvas 2D**, not a false WebGL claim.
- Dedicated 4D lab with interactive drag and speed control; independent network-analysis visualization in EyeGuard case study.
- Layered motion, spatial typography, fluid parallax, cinematic section entrances, timeline, focused PDF library.
- Respect for reduced-motion, lower-fidelity device performance and visibility/scroll-triggered pausing.
- No third-party JavaScript framework, no external trackers or analytics.

## Maintenance

## Controls
- `EXPLORE THE 4D LAB` opens an interactive mathematical 4D projection; drag to rotate, slider to change speed.
- Navigate using header anchors or the right-hand progress HUD, with Arrow Up/Down when not editing.
- Interact with the four EyeGuard pipeline tabs.

GitHub Pages deploys from the `main` branch, root directory.
