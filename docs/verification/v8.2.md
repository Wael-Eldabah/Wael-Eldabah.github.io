Browser control was unavailable in this session, so there are no new desktop/mobile screenshots, measured frame-rate results, or confirmed Safari video-alpha results. Contrast checks cover selected solid-color text/background pairs, not every translucent or animated composition. The still-art fallback remains in place for unsupported video alpha.

Previous browser evidence in this directory relates to earlier versions and must not be treated as visual verification of V8.2.
